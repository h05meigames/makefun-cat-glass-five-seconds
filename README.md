Entry for the [make.fun bounty "Five Seconds to Explain the Glass"](https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949): the single sentence a house cat would say in the five seconds after sweeping a glass off the table — at most 200 characters, in the cat's own voice, no apology and no confession.

## The sentence

> Your Honour, the glass stared at me first, and in this house a stare is a challenge, so I answered it the only way a cat can.

(125 characters, one sentence.)

## Run

```sh
node main.ts
```

`main.ts` (Node 22, no dependencies) prints the sentence to stdout and, when the grading sandbox provides it, writes it to `/output/entry.txt`. It throws if the sentence ever exceeds 200 characters.
